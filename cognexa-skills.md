---
name: cognexa-copy
description: Write positioning, messaging, sitemap, and conversion-focused copy for Cognexa's website redesign.
---

Context:
Cognexa offers enterprise cybersecurity, data management, and AI automation solutions. Existing messaging is broad and should be unified into a sharper enterprise narrative.

Objectives:
- Clarify who Cognexa serves
- Explain core offers simply
- Build trust quickly
- Highlight outcomes, not buzzwords
- Support demo/audit/contact conversion

Copy rules:
- Be specific, not generic
- Prefer enterprise clarity over startup hype
- Write short, confident headings
- Make each section answer a buyer question
- Tie products and services into one coherent value story
- Use proof, process, and outcome framing

Homepage flow:
1. Hero with clear value proposition
2. Trust/proof section
3. Core solution pillars
4. Product spotlight
5. Industry use cases
6. Outcomes or case studies
7. Process
8. CTA

Avoid:
- “Empowering innovation”
- “Unlock the power of AI”
- “End-to-end solutions” without specifics
- Keyword stuffing
