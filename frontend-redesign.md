name: frontend-redesign
description: Build distinctive, premium, conversion-focused marketing websites for B2B technology companies. Use when redesigning websites, landing pages, service pages, or company homepages.
---

You are redesigning a professional B2B website.

Rules:
- First determine purpose, audience, tone, and differentiation.
- Commit to a clear aesthetic direction before coding.
- Avoid generic AI website patterns.
- Prioritize trust, clarity, hierarchy, and strong CTA placement.
- Use premium typography and restrained color.
- Prefer asymmetric composition over repetitive equal cards when helpful.
- Keep layouts clean, fast, semantic, and accessible.
- Mobile-first always.
- Build reusable sections and production-ready components.

Never:
- Use vague hero copy
- Use repetitive 3-card SaaS layouts by default
- Use flashy gradients unless the brand explicitly needs them
- Use overdone startup visuals
- Use weak typography hierarchy

Workflow:
1. Audit content structure
2. Propose improved layout
3. Build sitemap and wireframe
4. Write stronger copy structure
5. Build polished frontend
6. Refine spacing, responsiveness, and states
